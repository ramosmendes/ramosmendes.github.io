Projetos destacados

Workspring — Sistema de gerenciamento de workshops

Java Spring Boot JPA PostgreSQL RESTful API

Sistema para gerenciar workshops e inscrições, substituindo controles manuais e planilhas por uma API centralizada.

  • Endpoints CRUD completos para workshops e participantes, construídos com Spring Boot 3.
  • Modelagem das entidades e relacionamentos do domínio com JPA, persistidos em PostgreSQL.
  • Validações e tratamento de exceções para manter a integridade dos dados.
  • Principal aprendizado: separar as camadas de controller, service e repository para manter a lógica de negócio desacoplada do acesso a dados.

LogSpring — Sistema de autenticação e autorização

Java Spring Security JWT Autenticação segura

Módulo de autenticação e autorização reutilizável para aplicações Java, com controle de acesso baseado em papéis de usuário.

  • Autenticação stateless com Spring Security e JSON Web Tokens (JWT).
  • Regras de autorização por role, restringindo endpoints conforme a permissão do usuário.
  • Filtros de segurança customizados para validar e renovar tokens a cada requisição.
  • Principal aprendizado: entender o fluxo completo de autenticação stateless e como reaproveitá-lo em diferentes aplicações Java.
